From SSH-ing into Pods to Actually Observing

Before this project, debugging a production issue on our B2B platform looked like this: figure out which country's deployment the report came from, SSH into the right pod, and grep through log files hoping the interesting line had not rotated away. For a repair-service portal running separately in seven countries, "which pod" was itself a research question.

Three tools, one query bar

Riding along with the Java 21 migration, I wired three things into more than nine services: ELK for centralized log aggregation, OpenTelemetry for traces, and Sentry for error tracking with alerting. None of these is exotic. The value was never the individual tool; it was retiring the SSH ritual across every service at once.

What rollout actually means

The work per service is mostly plumbing: logging configuration rewritten to ship structured JSON, an OpenTelemetry agent attached at the deployment level, Sentry SDK initialized with the right environment tags so a staging exception never pages anyone at night. The subtle part is consistency. Fifteen instances across seven countries only become one system in Kibana if service names, environment labels, and index patterns follow one convention. I wrote that convention down first and treated any deviation as a bug.

The payoff showed up immediately

The week after rollout, a country-specific bug report came in that would previously have meant an afternoon of pod spelunking. Instead it was one Kibana query across all seven country deployments, which showed the error appearing in exactly two of them, which pointed straight at a country-specific configuration difference. Minutes, not hours. Sentry then started surfacing errors nobody had reported at all, which is the quiet embarrassment of every observability rollout: the system was always failing a little; you just could not see it.

Lesson

Observability is infrastructure, not a feature. It never appears on a roadmap by itself, so the practical move is to attach it to work that already has momentum. A platform migration that touches every service anyway is the best delivery vehicle you will ever get.
